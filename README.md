# Sorty
## An interactive web-based sorting algorithm visualizer

<img width="2954" height="1710" alt="Screenshot 2026-07-29 151355" src="https://github.com/user-attachments/assets/8f2d9bed-a6bf-4f3d-90a9-6e56a0a5669b" />

### About the project:
Have you ever watched those addicting sorting algorithm videos with the moving bars and flashing colours?
Now you can experience it for yourself from the comfort of your browser.

Choose a sorting algorithms, shuffle, sort, and watch as the bars magically sort themselves.

<img width="2936" height="1722" alt="Screenshot 2026-07-29 151502" src="https://github.com/user-attachments/assets/42f6b1e6-455d-4532-bce5-290e93d288d1" />

### Features:
Main features include:
- 12 sorting algorithms
- Customizable amount of bars (n)
- Customizable base (only applies to some sorts)
- Customizable delay for read, write, and auxiliary operations
- Audio effects which use sine wave frequencies to represent bar heights
- RAINBOW MODE!!! (recommended for best experience)

### How it was made:
This project was made with HTML, CSS, and JS.
Seeing sorting visualization videos on Youtube inspired me to make it for myself
The most difficult part of the project for me was making the system used for rendering. The code is very spaghetti and there were many bugs to fix. 
Implementing the algorithms was also a complex task and I had to use help from online forums and pseudocode.

### AI Use:
- AI was used for tasks such as debugging or explaining complicated concepts
- Simpler sorting algorithms were implemented by hand
- More complex algorithms were implemented with the help of pseudocode
